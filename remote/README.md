# TV Viewer

Node.js + Electron 做的电视投屏窗口：Apple TV 式的深色界面，左边是 scrcpy 实时画面，右边是圆形点按板遥控器。底层不变——画面仍由 scrcpy 采集编码，按键通过 adb `input keyevent` 注入。

## 运行

安装版和便携版已经内置 scrcpy 5.0.1 和 adb，不需要另外安装；从源码运行则需要 Node.js 22+ 和 scrcpy。

```bash
cd remote
npm install     # 首次
npm start
```

或者直接双击 `tv-viewer.cmd`（不弹控制台）。

在画面区中央的连接卡里填电视 IP（不带端口会自动补 `:5555`），点「连接并投屏」。连接成功后画面会接管舞台，右侧遥控器点亮。

状态图标会跟着连接走：灰色断开的链环、黄色连接中、绿色已连接、红色失败；悬停看具体原因。失败时连接卡会显示具体原因并把焦点放回 IP 输入框，按钮变成「重新连接」；连接前遥控器整体禁用，避免误按。

窗口默认无边框，工具栏就是标题栏：左侧红黄绿交通灯（关闭 / 最小化 / 全屏），空白处可以拖动窗口；状态、断开、置顶、遥控器、铺满窗口、全屏都是图标控件，悬停显示说明。断开在连接后变成红色并放大，空闲或失败时是中性小图标。

## 显示模式

- **满窗口**（`Ctrl+Alt+W`）：隐藏顶栏和遥控器，画面铺满当前窗口，窗口大小和位置不变。
- **满屏幕**（`Ctrl+Alt+F` 或 `Ctrl+Alt+Enter`）：画面铺满整个显示器。
- 两种模式互斥；再按一次对应快捷键，或按 `Esc`（应用窗口有焦点时）退出。
- `Ctrl+Alt+H`：显示 / 隐藏右侧遥控器。

## 遥控器

- 方向键是圆形点按板，支持按住连发；OK = 确认。
- 返回 / 主页 / 菜单 / 最近 / 音量 +− / 静音 / 播放暂停 / 电源。
- 电源键不直接发送：每次都会先弹出「关闭电视？」确认，避免误关机。
- 连接后应用层也接方向键、回车、退格：焦点在界面里时直接控制电视，不必先点画面。点一下画面后仍可用 scrcpy 键位（方向键、回车确认、`Alt+B` 或右键返回）。

## 设置

工具栏的滑块图标打开设置页；打开时会暂时隐藏原生视频，关闭后恢复，所以设置页不会被投屏画面盖住。

- **语言**：中文 / English，切换后整个界面和错误文案立即更新，保存在本机。
- **启动时自动连接**：下次启动自动连接上次保存的电视。
- **掉线后自动重连**：scrcpy 异常退出后最多重试 3 次。
- **窗口置顶 / 显示遥控器**：和工具栏对应按钮同步。
- **方向键连发**：标准 / 快。

配置保存在 `%APPDATA%\TV Viewer\config.json`；旧版 `tv-viewer` / `tv-remote` 的配置会自动迁移。

## 原理

- `main.js`：`adb connect` → 启动 `scrcpy --window-borderless` → 通过 PowerShell 找到 scrcpy 窗口，`SetParent` 到 Electron 窗口，并定位到画面区域。Electron 窗口用 `frame: false` 创建，顶栏由网页绘制。
- `embed-scrcpy.ps1`：窗口嵌入和缩放。脚本声明了 DPI 感知，避免 150% 缩放下尺寸被二次放大。
- `renderer.js`：把画面区域的 CSS 矩形发给主进程；窗口尺寸变化时重新定位 scrcpy 子窗口。两种显示模式会隐藏网页界面，让画面区域扩展到整个窗口或屏幕。
- 按键：渲染进程 → IPC → `adb shell input keyevent KEYCODE_*`，不依赖 scrcpy 窗口是否获得焦点。

## 已验证

- Windows 11，屏幕 2560×1440 / 150% 缩放。
- 小米 MFTR0，Android 11，1920×1080：连接、窗口嵌入、音量 + / − / 静音按钮端到端验证通过。
- 默认无边框、顶栏拖动、交通灯全屏、满窗口 / 满屏幕切换、`Ctrl+Alt+W` / `Ctrl+Alt+F` / `Ctrl+Alt+H` 快捷键已验证；满屏幕下画面确实铺满显示器。
- Apple/tvOS 深色改版：空闲、连接、错误、窄窗口（900 DIP）四态已渲染检查；检测器 `impeccable detect` 为 0 条 findings。
- 设置页、中英文切换、电源确认、自动连接、掉线自动重连、红色放大断开图标均已实测；设置页在连接态能正确隐藏/恢复原生画面。
- Windows 安装版和便携版已启动验证；打包后的 `resources\scrcpy` 中 adb / scrcpy 可执行，界面资源完整。
- scrcpy 5.0.1、Electron 45。

## 注意

- 满窗口 / 满屏幕时，画面是原生子窗口，会盖住网页里的按钮和提示；退出请用快捷键（`Esc`、`Ctrl+Alt+W`、`Ctrl+Alt+F`）。
- 打包版使用安装目录 `resources\scrcpy` 里的内置 scrcpy / adb；源码运行时从 PATH 或默认安装位置查找（winget 的 scrcpy、Android SDK 的 platform-tools），也可以用 `SCRCPY` / `ADB` 环境变量指定完整路径。
- `TV` 环境变量可以预填电视地址。
- 投屏用原生分辨率；不要加 `--max-size=1600`，那台电视会花屏（见上层 `README.md`）。
- 同一台电视只开一个投屏实例。
- 测帧率、动效前先点断开图标：电视端编码会占 GPU/编码器。
- 如果窗口嵌入失败，scrcpy 会退化为单独窗口显示，遥控器仍然可用。
