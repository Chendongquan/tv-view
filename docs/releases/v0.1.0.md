# TV Viewer 0.1.0

首个公开版本：把 Android TV 画面嵌入桌面窗口，用屏幕遥控器或键盘直接操作。电视端不安装 App，不经过第三方服务器。

## 下载

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `tv-viewer-setup-0.1.0-x64.exe` | 116 MB | 安装版，按用户安装，不需要管理员权限 |
| `tv-viewer-portable-0.1.0-x64.exe` | 106 MB | 便携版，首次启动会解压到临时目录 |
| `SHA256SUMS.txt` | — | 校验文件 |

```bash
sha256sum -c SHA256SUMS.txt
```

安装包只包含应用本身，不包含 scrcpy / adb。使用前先安装 scrcpy（自带 adb）：

```bash
winget install Genymobile.scrcpy
```

安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”；请只从本仓库 Releases 下载并核对 SHA256。

## 包含

- Electron 45 桌面应用，scrcpy 画面嵌入单窗口。
- 圆形点按板遥控器：方向键（按住连发）、OK、返回、主页、菜单、最近、音量 ±、静音、播放/暂停、电源。
- 电源键始终二次确认。
- 无边框窗口：交通灯、拖动顶栏、置顶、铺满窗口、全屏。
- 设置：中 / 英文、启动自动连接、掉线自动重连、方向键连发速度、窗口置顶、显示遥控器。
- 掉线自动重连（最多 3 次）；嵌入失败时退化为独立 scrcpy 窗口。
- 命令行工具：`tv-view` 查看画面、`tv-shot` 截图（兼容 Android 4.x）。
- Windows 安装版和便携版，只包含应用本身；scrcpy / adb 需要单独安装。
- 第三方许可说明：`THIRD_PARTY_NOTICES.md`。

## 已验证

- Windows 11，2560×1440，150% 缩放。
- 小米 MFTR0，Android 11，1920×1080。
- 打包后的安装版/便携版启动正常，内置 adb / scrcpy 可执行，界面资源完整。
- scrcpy 5.0.1，Electron 45。

## 已知限制

- GUI 仅 Windows；命令行脚本可在 macOS / Linux 使用。
- 无音频转发。
- 满窗口 / 全屏时原生视频会盖住网页控件，退出依赖快捷键。
- 一个窗口一台电视；同一台电视只开一个 scrcpy。
- 小米 MFTR0 上不要用 `--max-size=1600`，用 `1280` 或原生分辨率。
- 安装包未签名；没有自动更新。
- Android 4.x 只能截图，画面功能要求 Android 5.0+。
